# Relationships

## Overview

Relationships define how records in one table connect to records in another table.

They are a core part of relational database design.

## Common Types

- one-to-one
- one-to-many
- many-to-many

## Why They Matter

Real backend systems rarely store completely isolated data.

Examples:

- a user has many orders
- an order belongs to one user
- a product can belong to many categories

Relationships let the database represent these connections clearly.

## Summary

Relationships are fundamental for modeling real-world data correctly in relational databases.
