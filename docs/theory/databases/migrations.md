# Migrations

## Overview

Migrations are versioned changes to the database schema.

They let the schema evolve in a controlled and repeatable way.

## Why They Matter

As applications grow, tables and constraints change.

Migrations help teams:

- track schema history
- apply changes safely
- keep environments consistent

## Good Practice

- commit migrations to version control
- review them carefully
- apply them in a controlled process

## Summary

Migrations are the standard way to evolve a database schema without losing control over change history.
