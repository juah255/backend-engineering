# Joins

## Overview

Joins combine data from multiple tables based on their relationships.

They are a key part of SQL querying in relational databases.

## Why Joins Matter

Backend systems often need connected data rather than isolated rows.

Examples:

- orders with user information
- posts with author data
- URLs with owner details

## Common Join Types

- `INNER JOIN`
- `LEFT JOIN`
- `RIGHT JOIN`

In practice, `INNER JOIN` and `LEFT JOIN` are the most common.

## Summary

Joins allow relational data to be queried in meaningful combined forms, which is central to backend data access.
