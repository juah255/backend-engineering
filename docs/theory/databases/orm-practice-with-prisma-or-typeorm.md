# ORM Practice with Prisma or TypeORM

## Overview

An ORM, or Object-Relational Mapper, helps application code work with relational databases through higher-level abstractions.

In NestJS, Prisma and TypeORM are common choices.

## Why ORMs Matter

They help with:

- query construction
- schema modeling
- migrations
- type safety, depending on the tool
- integration with application code

## Prisma

Prisma is known for:

- strong developer experience
- generated typed client
- schema-first workflow

## TypeORM

TypeORM is known for:

- entity-based modeling
- deep NestJS familiarity
- traditional ORM patterns

## Practical Guidance

Use the ORM as a tool, not as a reason to ignore SQL fundamentals. A backend engineer still needs to understand joins, indexes, transactions, and query cost.

## Summary

Prisma and TypeORM can improve productivity, but strong backend work still depends on understanding the underlying database behavior.
