# Passport in NestJS

## Overview

Passport is an authentication middleware ecosystem commonly used in NestJS through official integration packages.

It helps structure authentication strategies such as local login or JWT validation.

## Why It Matters

Passport gives NestJS a standard way to implement authentication flows without building everything manually.

## Common Uses

- local strategy for username or password login
- JWT strategy for protected routes
- guards built around strategies

## Practical Guidance

Passport is useful, but you still need to understand the underlying authentication flow. It does not replace clear access design.

## Summary

Passport provides strategy-based authentication support in NestJS and is a common foundation for login and token validation flows.
