# Role-Based Access Control

## Overview

Role-Based Access Control, or RBAC, grants access based on user roles.

Examples of roles include:

- admin
- editor
- user

## Why It Matters

RBAC is simple to understand and works well when permissions naturally group by role.

## Benefits

- straightforward mental model
- easy to apply in route protection
- common fit for many business apps

## Limitation

RBAC can become rigid when access rules are more detailed than role labels can express.

## Summary

RBAC is a practical access model for many systems, especially when user responsibilities are clearly grouped into roles.
